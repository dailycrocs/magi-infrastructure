# MAGI Literature Notes

This directory contains notes for sources used to research and design the
MAGI Infrastructure project.

Sources may include:

- Peer-reviewed research papers
- Technical standards
- Government publications
- Official product documentation
- Other reliable technical references

## Research Workflow

A source should be opened and reviewed before it is added to the project
bibliography.

For each useful source:

1. Read the source.
2. Create a Markdown note in this directory.
3. Record what the source contributes to MAGI.
4. Record relevant findings, page numbers, sections, or technical details.
5. Verify the citation information.
6. Add the source to `paper/references.bib` only after it has been reviewed.

AI-generated citations should not be accepted without checking the original
source.
