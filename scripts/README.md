# MAGI Scripts

This directory contains reusable scripts that support the operation,
monitoring, testing, and maintenance of the MAGI Infrastructure project.

Scripts placed here are intended to become part of the working MAGI
environment.

Experimental or proof-of-concept scripts should first be developed and
tested under `sandbox/`.

Potential script categories may include:

- Monitoring and health checks
- Networking and connectivity verification
- Configuration backups
- Reporting
- Security testing support

Directories will be added as scripts are developed through project issues.

## Verification

Each script must be reviewed and tested before it is accepted into MAGI.

Substantial agent-assisted work must also be recorded in `AGENT-LOG.md`,
including what was personally verified before the work was accepted.
