# MAGI Sandbox

This directory contains small experiments used to investigate technologies,
configurations, protocols, scripts, or other behaviors relevant to MAGI.

Each experiment should have its own directory and README describing:

1. What is being tested.
2. Why the test is relevant to MAGI.
3. How the experiment can be reproduced.
4. What the experiment demonstrated.

Experimental work in this directory is not considered part of the production
MAGI infrastructure.

If an experiment becomes something MAGI depends on, it should be moved into
the appropriate project directory and tested as part of a separate issue.
